Enable Cross-Chat Prompt Sharing

This module streamlines your workflow when using multiple AI chat services.

  • How it works: On a supported chat page (like ChatGPT), type a prompt and click the 📋 button. Then, navigate to another chat page (like Claude) and click the 📥 button to paste the same prompt.

Token Counter (Approximator) (click to expand)

▶
Enable ChatGPT Token Approximator

⚠️ For high performance computers only — gets slower with longer conversations!

Estimates tokens locally in your browser. Shows T (thread) and E (editor) chips that auto-refresh and can be clicked. Results are rough, especially with code/non-latin characters. Token counter CANNOT count tokens in files you upload!

Accuracy: English ±2k below ~10k tokens, ±10k above. Code/non-English: expect ~50% error. Beyond ~100k: directional only.

Why care? Models degrade as context grows—knowing if you're at ~50k vs ~100k helps you decide to trim/chunk/summarize. Plus, after specific model token limit, chat may "forget" previous messages: this is not guaranteed, as web chats are "black box" - there might be some sort of RAG for previous messages, however, RAG is not as good as direct token input.

For more information, check model limits/benchmarks (e.g., NoLiMa). For exact counts use the official tokenizer.

▶ Show model details

Ultralight State Machine ⭐ ⚡ Fastest, good accuracy

This scanner walks the string character by character, toggling an inWord flag to start a new token when word-like characters begin. Each CJK character and each separator symbol increments the token count, while spaces only reset the state. It aims for portability and speed without big regexes, sacrificing some nuance versus the blended model.

Single Regex Pass ✓ Accurate

A single Unicode regex matches letter sequences, numbers, individual CJK characters, or any non-whitespace symbol and returns the total matches as the token estimate. 30% slower than Ultralight state machine. The trade-off is coarse granularity—punctuation and symbols count as their own tokens, and there's no adjustment for code-heavy or CJK-heavy text.

Simple 1:4 Ratio ⚠️ Less accurate

Simple approximation: 1 token ≈ 4 characters. Very fast and uses minimal CPU, but less accurate especially with code or non-English text. Good for modest machines or extremely long chats where speed matters more than precision.

Advanced Heuristics 🐢 Slower, lowest accuracy, underestimates a lot.

Uses intelligent heuristics that adapt to different content types (code, CJK text, etc.) for better accuracy. Can use significant CPU on very long conversations. Blends word-based and character-based estimates.

CPT Blend/Mix 🐌 Slow, but sometimes good accuracy.

Sometimes best accuracy, sometimes off. 70% slower than Ultralight state machine. It first normalizes the text and gets a word-based count, then computes a character-per-token estimate weighted by content type. Code-ish text and CJK are detected with targeted regexes to adjust CPT and to derive ratios. The final estimate blends the word and char counts with scenario-specific weights and clamps divergence.

Buttons & Hotkeys

  • Autosend override: Pressing "Shift" while pressing a key or button changes its autosend behavior! Works both with clicks and keyboard shortcuts!
  • Keyboard shortcuts: Keyboard shortcuts can be enabled in Settings section. Default shortcuts still show as Alt+1 through Alt+0 so you can see that hotkeying is possible.
  • Editable hotkeys: Click the shortcut chip on a button card to open the hotkey picker. It records Chrome-safe shortcuts, validates reserved combinations, and warns before moving a shortcut away from another button.
  • Add Settings button: You can add Settings button (⚙️) by pressing the "Add Settings button" in Button Configuration. Shift-click that button on a chat page to move where OneClickPrompts injects its buttons.
  • Copy Last ChatGPT Response button: Add this special button from Button Configuration. It works only on ChatGPT and tries ChatGPT's native Copy action first so formatting is as exact as ChatGPT provides.
  • Move Buttons Container: If buttons are in a weird place, hold Shift and click the Settings button (⚙️) to enter Move Mode, then use the arrows to reposition them. In Move Mode, the small × on the floating panel launcher (🔼) hides that launcher for the current profile.
  • Edit buttons on-page: Ctrl+Shift-click the Settings button (⚙️) on a chat page to make custom buttons and separators shake. Drag buttons or separators to reorder them, or click the small × to delete one. Click Settings once again to leave edit mode.

Floating Panel & Queue

  • Floating panel: Click the 🔼 button on the chat page to open the draggable floating panel. It can hold prompt buttons, profile switching, and queue controls.
  • Interface scale: Use the Settings scale slider to resize both the injected on-page buttons and the floating panel. Scale is saved with the current profile.
  • Queue Feature: Queue sends multiple prompts sequentially with a configurable delay. Configure delay and random offset in Floating Window Settings. Use it responsibly and in accordance with the website's Terms of Service.
  • Queue Button: Add the special Queue button (⏳) from Button Configuration. It queues the current editor text, clears the editor so you can write the next item, and sends after the configured queue delay.
  • Queue controls in chat: When the Queue button adds items, a small tab-like queue control appears at the bottom of the injected button row. It mirrors the floating panel queue: play/pause, skip, reset, progress, and queued items all operate on the same shared queue.

Setup & Safety

  • Open Welcome page with instructions again
  • Backups: Export profiles you care about before updates or experiments. Browser extension storage can be fragile, and backups are the fastest way to recover your buttons.
  • Profiles: Use profiles for different workflows. You can copy a profile before trying big changes.
  • Introducing changes faster than once in second causes saving issues.

Modules & Troubleshooting

  • Cross-Chat Prompt Sharing: Enable it in Modules to add 📋 and 📥 buttons. It lets you copy a prompt from one AI chat and paste it into another without using the system clipboard.
  • Inline Profile Selector: Enable it in Modules by toggling “Show profile selector in button row”. Choose placement before or after custom buttons, then switch profiles directly from the button row.
  • In case of a problem: first step is to reload your browser.
  • If buttons or auto-clicking stop working, go to Settings and open "Advanced Selector Configuration". Turn on heuristics for the editor, send button, and stop button. The extension will then try to auto-detect the places where buttons are injected and where clicks should happen, even if the website changed its structure.
  • In case something stopped working completely: websites often change their structure. The extension may need selector updates, and then it can take time for Google to approve a new version.
  • In case something is not working: try to use English version of the websites. LLMs do not care about language, so you can use any language you want in chat, while keeping interface language English. I only test on English interfaces.
  • If buttons disappear, first refresh the page, then try Advanced Selector Configuration and press "reset ALL Websites' Selectors". If you are using floating window, also try "Reset Floating Window Settings for all pages". You can open an issue on Github: Issues page or email me at forpphotos@gmail.com.
  • If absolutely nothing works: export needed profiles, uninstall the extension, install it again, test with default profiles, then import your saved profiles and test again.

Help (click to expand)

▶

Configure custom CSS selectors for different AI chat platforms. Each selector type can have multiple fallback options defined as an array. The extension will use the first matching selector found on the page, with subsequent entries serving as fallbacks.

  • Containers: The parent elements that contain the chat interface. These elements will host your custom buttons.
  • Send Button: The submit buttons that send messages. For auto-sending buttons, the extension will automatically trigger these after inserting text.
  • Stop Button: When you are trying to use button that autosends, but AI is typing, this safeguards against searching for send button.
  • Editors: The text input areas where messages are composed. Note that the editor selector might need to be different for empty chats versus chats with existing messages.
  • Container ID: A unique identifier for the extension's button container. This is primarily used for internal detection and troubleshooting - modification usually isn't necessary.
  • Thread: Thread is where token counter tries to count tokens. If token coding doesn't work properly, you can try changing the thread selector. However, sometimes websites break this functionality beyond selecting specific selectors, so only I can fix it. If something is off, reset selectors for the specific site - but be careful: the extension does not update defaults as fast as websites change, so default selectors may fail.
  • buttonsContainerId: buttonsContainerId is an internal identifier for the buttons container. You usually don't need to change it.

Format: JSON array for containers/sendButtons/editors, string for buttonsContainerId

Auto-Detection (Heuristics)

If something doesn't work on a website, enable the matching heuristic. The extension will try to find elements automatically.

  • Editor: Can't insert text? Enable this. Searches for text input areas on the page.
  • Send Button: Auto-send not working? Enable this. Searches for the Send button near the text input.
  • Stop Button: Extension clicks Send while AI is typing? Enable this. Helps detect when AI is still generating a response.
  • Injection Target: Buttons don't appear at all? Enable this. Searches for an alternative place to insert the extension's buttons.

All heuristics are off by default. Turn them on only if you have problems.
